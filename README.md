# Q-Panel · 日常工作台

> 面向任何行业的个人日常工作台：**季度规划 → 本周安排 → 全局项目**，容量、提醒和 AI 串成一条闭环。示例数据使用安全工作场景，Q-Panel 本身不限定行业。

当前仓库包含 **v1.1.27 Electron 应用**：启动后折叠为覆盖物理刘海的透明点击热区（不显示 Dock 图标），鼠标悬停刘海下方显示石墨金属轮廓与单次镜面扫光（无箭头、无循环呼吸）；点击刘海/托盘/默认 ⌘⇧Space 切换打开与收起（快捷键可自定义），点击外部空白自动收起；四套皮肤、人日容量、项目全局规划/本季排期、提醒、真实 AI、可调背景模糊与 ⌘K 全局跳转均已落地。

## 快速打开

```bash
cd prototype
npm install
npm run dev
```

然后打开 **http://127.0.0.1:5178/**，建议按 `⌃⌘F` 全屏。

> 原型服务器当前也在运行；如果页面打不开，按上面命令重启即可。

## 这一版的核心变化

- **刘海优先**：启动不展开窗口，点击真实刘海热区展开；面板始终置顶，失焦自动收起并恢复刘海热区；
- **品牌与可读性**：新的待办勾选面板 Logo / App 图标；背景使用不透底合成层，单一模糊滑块按帧预览；100% 完全隔离桌面，任务卡片保持稳定对比度；桌面快照只在内存中用于磨砂氛围，无录屏权限时使用纯色安全材质；
- **所有计划/任务/项目都有按天的开始–结束时间段**；到期提醒使用结束日和 24 小时制整点；
- **所有时间统一按人日**：1 人日 = 1 个正常工作日；不再按小时换算，支持 0.25 / 0.5 人日。
- 季度规划容量改为 **本季度**：可用人日 = 工作日 − 请假；已占用 = 季度任务 + 未关联季度任务的项目本季工作项（关联项目工作项不重复计）；剩余可为负数。
- **项目是全局维度**：项目总规划、工作项、里程碑跨季度；当前季度只计算 Q4 排期，项目页与项目详情都明确区分「全局 / 本季度」。
- 跨季度项目显示 **跨季度** 标识；只有工作项总规划超过项目总规划时才显示 **有延期风险**。
- 项目工作项仍按「安排周」自动进入本周安排，并计入当周已排人日；周容量不足会显示负数。
- 周页保留上一周 / 下一周 / 回到本周。
- 侧边栏按优先级分两组：**规划与推进（季度规划 / 本周安排 / 项目·全局）→ 其它（临时笔记 / 收藏链接）**；
- 页面标题去重：季度页「Q4 季度规划」、周页只写「第 42 周」、项目页只写「全局项目」；
- 项目页改成**项目概览行**：先看全局总规划 / 本季排期 / 里程碑 / 风险，点一行再进入工作规划详情；
- 分类支持新增/删除：筛选行、项目页、设置或新建事项弹窗里都能直接新增，颜色可选，并即时出现在所有选择器；自定义分类可在设置里删除，内置分类保留；
- 侧边栏分组名可在 **设置 → 侧边栏** 自定义，导航项与顺序保持固定；
- 临时笔记和收藏链接已经回到侧边栏其它组；收藏链接按「集合 + 列表」管理，支持新增、编辑、删除、自定义集合标签和搜索。
- 所有截止/目标日期都带 **24 小时制时刻（HH:mm）**；新建表单使用自定义日期时间选择器，提醒弹窗与后续 macOS 系统通知都按精确时间计算；
- 提醒默认值集中在 **设置 → 提醒**（提前量 + 24h 时刻），新建任务/项目可单独覆盖，不指定则跟随全局；
- 动效层：指针追光、页面内容级联入场、容量数字滚动、环形图/堆叠条生长、主题 View Transition 转场；悬停事项时关联季度任务/项目同步高亮、其余事项变暗，并绘制带流光的关系曲线；反向悬停季度任务/项目卡片也会聚焦回本周事项；全部支持 `prefers-reduced-motion`。

## 现在可以直接体验

1. 季度规划 Q4：**可用 60 / 已占用 48.5 / 剩余 11.5 人日**；其中季度任务 48、独立项目 0.5；
2. 季度规划左侧本周容量：**5.25 / 5 人日**，已超 0.25 人日；
3. 点「本周安排」→ W42 已排 5.25 人日；W43 请假 2 天后可用 3 人日、已排 4.25，显示 **-1.25 人日**；
4. 点「项目」→ 项目概览行「等保 2.0 整改」→ 编辑全局总规划人日、工作项人日、安排周；项目跨季度，显示 **跨季度**；
5. 工作项改安排周后打开本周安排，可看到「项目自动排期」同步；项目详情右侧也能直接点 **2027 第 1 周**，自动切到 2027 Q1 并看跨季度排期；
6. 右上角 AI → 点「把 Q4 应用安全任务拆成本周 3 件事」→ 确认写入；
7. 右上角铃铛 → 完成 / 稍后 / 打开提醒；
8. 侧边栏「其它」→ 临时笔记 / 收藏链接；
9. 右上角调色盘循环切换 **Noir / Ops / Aurora / Ember** 四套皮肤。

提醒弹窗会在打开页面约 5 秒后自动弹一次；不想被它打断用 `?noreminder=1`。

## 当前口径

- 正式版使用系统当前时间（Asia/Shanghai）；原型截图与自动化测试通过 `?now=2026-10-17T19:22:00+08:00` 冻结时间；
- 2026 Q4：62 个工作日 − 2 天年假 = **60 人日可用**；
- 本季度任务 48 人日 + 独立项目 0.5 人日 = 已占用 48.5 人日，完成度 38%；
- 全局项目 5 个、总规划 50 人日，其中 3 个跨季度；
- 2026 全年：按内置日历引擎计算 **247 个工作日 / 245 人日可用**（Q1 59 / Q2 61 / Q3 65 / Q4 62，Q4 扣 2 天年假）；
- 周次由 ISO 周规则动态生成（2025–2028），默认打开当前周/当前季度；设置调整后季/周/月容量实时重算；
- 设置 → 人日与日历可以新增/删除请假占用，季度、周、月容量会实时重算并持久化；
- 2026 官方日历：10/1–10/7 国庆假、10/10 调休上班、10/20–10/21 年假；
- 2027 官方安排未发布时，明确提示“按周末规则估算，可手动补充”，不编造节假日。
