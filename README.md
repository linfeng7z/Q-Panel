# Q-Panel · 安全工作台

> 给应用安全负责人自用的季度作战工作台：**年/Q 主线 → 周必做 → 长期项目里程碑**，容量、提醒和 AI 串成一条闭环。

当前仓库包含 **v0.1 可点击 UI 原型**：高保真假数据、两套皮肤、7 个页面、AI 抽屉、提醒弹窗和 ⌘K 全局跳转。正式功能版会落到 Electron 的 Mac 刘海贴顶面板。

## 快速打开

```bash
cd prototype
npm install
npm run dev
```

然后打开 **http://127.0.0.1:5178/**，建议按 `⌃⌘F` 全屏。

> 原型服务器当前也在运行；如果页面打不开，按上面命令重启即可。

## 这一步要你确认什么

1. **视觉方向**：Noir（黑玻璃）与 Ops（数据看板）两套皮肤是否都成立、哪套默认；
2. **信息密度**：正文字号、行高、卡片留白在你 14/16 寸 Mac 上是否舒服；
3. **信息架构**：今日 / 季度 / 周 / 项目 / 统计 / 笔记 / 链接的优先级与默认展开页；
4. **交互取舍**：周列表滚动、季度页右侧卡片、AI 抽屉宽度、提醒弹窗位置；
5. 确认后进入 Electron P0（真实刘海窗口 / 菜单栏 / 本地存储 / 系统通知）。

## 产品一句话

不是通用待办，而是「容量约束下的目标管理」：

- 季度先算可用工时（中国法定节假日 + 调休补班 + 请假扣减），再排主线计划工时；
- 周必做可关联季度主线和长期项目，项目用里程碑进度条回答“这件事到哪了”；
- 每个事项可按「提前 N 天」设置默认提醒，到点在 Mac 上弹窗；
- AI 负责把自然语言变成事项/项目，写入前必须预览确认。

## 原型已覆盖

- **刘海形态**：200px 收起态 ↔ 1280×760 展开态，点桌面 / `Esc` 收起；
- **今日**：休息日、到期、逾期、本周进度、季度容量、下一步里程碑；
- **季度**：62 天 / 480h 容量、384h 已分配、分类工时条、季度主线列表、年度总览；
- **周**：第 42 周日历条、容量条、本周必做、逾期搬运、关联主线/项目；
- **项目**：5 个长期项目、里程碑时间线、加权进度、详情弹层；
- **统计**：2026 全年 248 天 / 1968h、季度/月/周拆分、工作日历热力图；
- **笔记 / 链接**：保留原版你选中的两个轻量工具；
- **AI**：流式质感对话、提案卡、确认写入本周；
- **提醒**：顶部不抢焦点弹窗，完成 / 稍后 / 打开；
- **两套皮肤** + 设置弹层 + ⌘K 命令面板。

更细的体验说明见 [prototype/README.md](prototype/README.md)，产品与技术方案见 [docs/PRODUCT-PLAN.md](docs/PRODUCT-PLAN.md)。
