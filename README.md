# Q-Panel · 安全工作台

> 给应用安全负责人自用的季度作战工作台：**季度任务 → 周计划 → 长期项目里程碑**，容量、提醒和 AI 串成一条闭环。

当前仓库包含 **v0.2 可点击 UI 原型**：高保真假数据、两套皮肤、三项主工作台、项目工时规划与自动排期、AI 抽屉、提醒弹窗和 ⌘K 全局跳转。正式功能版会落到 Electron 的 Mac 刘海贴顶面板。

## 快速打开

```bash
cd prototype
npm install
npm run dev
```

然后打开 **http://127.0.0.1:5178/**，建议按 `⌃⌘F` 全屏。

> 原型服务器当前也在运行；如果页面打不开，按上面命令重启即可。

## 这一步按你的反馈改了什么

- 侧边栏从 7 项收敛为 **3 项**：首页（季度任务）/ 周计划 / 项目；统计、随笔记、链接收藏收进顶栏「工具」菜单。
- 季度页成为默认首页，名称改为 **季度任务**。
- 项目进入后是完整 **工作规划** 页：
  - 可编辑项目 **总规划工时**；
  - 可增删、改名、改工时、改安排周的 **工作项**；
  - 工作项按安排周**自动进入周计划的「项目自动排期」**，并计入当周已排工时；
  - 右侧显示周排期和里程碑，点周次可直接跳到对应周。
- 周页新增醒目的 **上一周 / 下一周 / 回到本周** 切换条，项目自动排期会计入周容量；超载会直接显示红色负剩余。
- 保留的两套皮肤、AI、提醒、⌘K 均继续可用。

## 现在可以直接体验

1. 默认首页是 Q4 季度任务：容量 480h / 已分配 384h / 剩余 96h；
2. 点「周计划」→ 看「项目自动排期」自动带入 4 个工作项（13h）；
3. 点「下一周」→ W43 因为请了 2 天假，周容量 24h、已排 32h，会显示 **-8h 超载**；
4. 点「项目」→「等保 2.0 整改」→ 编辑总规划工时、工作项工时、安排周，改完打开周计划即可看到自动同步；
5. 右上角 AI → 点「把 Q4 应用安全任务拆成本周 3 件事」→ 确认写入；
6. 右上角铃铛 → 完成 / 稍后 / 打开提醒；
7. 右上角「工具」菜单 → 统计与容量 / 随笔记 / 链接收藏；
8. 右上角调色盘切换 Noir / Ops。

提醒弹窗会在打开页面约 5 秒后自动弹一次；不想被它打断用 `?noreminder=1`。
