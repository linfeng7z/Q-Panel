# Q-Panel · 日常工作台

> 面向任何行业的个人日常工作台：**季度规划 → 本周安排 → 全局项目**，容量、提醒和 AI 串成一条闭环。示例数据使用安全工作场景，Q-Panel 本身不限定行业。

当前仓库包含 **v0.4 可点击 UI 原型**：高保真假数据、四套皮肤、分组侧边栏、**人日口径**、项目全局规划/本季排期、自动排期、可新增/删除分类、AI 抽屉、提醒弹窗和 ⌘K 全局跳转。正式功能版会落到 Electron 的 Mac 刘海贴顶面板。

## 快速打开

```bash
cd prototype
npm install
npm run dev
```

然后打开 **http://127.0.0.1:5178/**，建议按 `⌃⌘F` 全屏。

> 原型服务器当前也在运行；如果页面打不开，按上面命令重启即可。

## 这一版的核心变化

- **所有时间统一按人日**：1 人日 = 1 个正常工作日；不再按小时换算，支持 0.25 / 0.5 人日。
- 季度规划容量改为 **本季度**：可用人日 = 工作日 − 请假；已占用 = 本季度任务 + 本季度项目排期；剩余可为负数。
- **项目是全局维度**：项目总规划、工作项、里程碑跨季度；当前季度只计算 Q4 排期，项目页与项目详情都明确区分「全局 / 本季度」。
- 跨季度项目会显示 **跨季度 / 有风险** 标识；本季度排期超出容量的项目也会被列入风险。
- 项目工作项仍按「安排周」自动进入本周安排，并计入当周已排人日；周容量不足会显示负数。
- 周页保留上一周 / 下一周 / 回到本周。
- 侧边栏按优先级分两组：**规划与推进（季度规划 / 本周安排 / 项目·全局）→ 其它（容量与复盘 / 临时笔记 / 收藏链接）**；
- 页面标题去重：季度页「Q4 季度规划」、周页只写「第 42 周」、项目页只写「全局项目」；
- 项目页改成**项目概览行**：先看全局总规划 / 本季排期 / 里程碑 / 风险，点一行再进入工作规划详情；
- 分类支持新增/删除：筛选行、项目页、设置或新建事项弹窗里都能直接新增，颜色可选，并即时出现在所有选择器；自定义分类可在设置里删除，内置分类保留；
- 侧边栏分组名可在 **设置 → 侧边栏** 自定义，导航项与顺序保持固定；
- 临时笔记和收藏链接已经回到侧边栏其它组。
- 所有截止/目标日期都带 **24 小时制时刻（HH:mm）**；新建表单使用自定义日期时间选择器，提醒弹窗与后续 macOS 系统通知都按精确时间计算；
- 提醒默认值集中在 **设置 → 提醒**（提前量 + 24h 时刻），新建任务/项目可单独覆盖，不指定则跟随全局；
- 动效层：指针追光、页面内容级联入场、进度条生长、主题切换柔化、交互按压反馈，支持 `prefers-reduced-motion`。

## 现在可以直接体验

1. 季度规划 Q4：**可用 60 / 已占用 58.5 / 剩余 1.5 人日**；其中季度任务 48、项目本季排期 10.5；
2. 季度规划左侧本周容量：**5.25 / 5 人日**，已超 0.25 人日；
3. 点「本周安排」→ W42 已排 5.25 人日；W43 请假 2 天后可用 3 人日、已排 4.25，显示 **-1.25 人日**；
4. 点「项目」→ 项目概览行「等保 2.0 整改」→ 编辑全局总规划人日、工作项人日、安排周；项目跨季度，显示 **有风险**；
5. 工作项改安排周后打开本周安排，可看到「项目自动排期」同步；项目详情右侧也能直接点 **2027 第 1 周**，自动切到 2027 Q1 并看跨季度排期；
6. 右上角 AI → 点「把 Q4 应用安全任务拆成本周 3 件事」→ 确认写入；
7. 右上角铃铛 → 完成 / 稍后 / 打开提醒；
8. 侧边栏「其它」→ 容量与复盘 / 临时笔记 / 收藏链接；
9. 右上角调色盘循环切换 **Noir / Ops / Aurora / Ember** 四套皮肤。

提醒弹窗会在打开页面约 5 秒后自动弹一次；不想被它打断用 `?noreminder=1`。

## 当前口径
