# Q-Panel · 可点击 UI 原型

Q-Panel 是面向任何行业的「日常工作台」：季度规划 → 本周安排 → 全局项目，容量、提醒和 AI 串成一条闭环。示例数据使用安全工作场景，产品本身不限定行业。

**当前阶段：v0.5 Electron P0 的渲染层与视觉试验场。正式版入口见 `electron/`；原型仍用假数据，不接真实模型。**

## 立即体验

正式桌面版：

```bash
cd ../electron
npm install
npm run build
npm start
```

或单独跑原型开发服务器：

```bash
npm run dev
# http://127.0.0.1:5178/
```

建议浏览器 `⌃⌘F` 全屏，获得最接近 Mac 刘海面板的体验。

如果服务器停了：

```bash
cd prototype
npm install
npm run dev
```

## 分组侧边栏

侧边栏按内容分两组，小字标签是分组标题：

- **规划与推进**：季度规划 / 本周安排 / 项目（全局）
- **其它**：容量与复盘 / 临时笔记 / 收藏链接

页面标题也做了去重：季度页是「Q4 季度规划」，周页只写「第 42 周」，项目页只写「全局项目」。分组名可在 **设置 → 侧边栏** 里改，导航项和顺序保持不变。

## 项目页先看概览，再看细节

项目页是一行一个项目：先快速看到全局规划、本季排期、已拆解、里程碑、风险和进度；点某一行才进入项目详情，编辑总人日、工作项、安排周和查看周排期。

分类可以在 **设置 → 分类** 里新增、点筛选行右边的 **+ 分类**，或直接在新建事项的「+ 新建分类」里完成。新增后立即出现在季度任务/本周事项/项目的选择器和筛选器里；自定义分类可在设置里删除，仍被事项使用的分类会先提示移走。

## 动效与皮肤

- 四套皮肤：Noir / Ops / Aurora / Ember；
- 指针追光、页面内容级联入场、容量数字滚动、环形图/堆叠条生长；
- 悬停本周事项：关联季度任务/项目同步高亮，其他事项变暗，并用带流光脉冲的动态曲线把三层关系连起来；悬停侧栏的任务/项目卡片也会反向聚焦相关事项；
- 切主题时使用 View Transition 做整页材质过渡；
- 全部动效支持 `prefers-reduced-motion`。

## 人日口径（这一版重点）

- **1 人日 = 1 个正常工作日**；不再按小时折算；
- 支持 `0.25 / 0.5 / 0.75 / 1.25` 等半天粒度；
- 截止/目标日期统一带 `HH:mm` 24 小时制时刻，并使用自定义日期时间选择器；提醒与系统通知精确到分钟；
- 设置 → 提醒 设全局默认（提前量 + 时刻），新建任务/项目可单独覆盖；
- 季度可用 = 工作日 − 请假/占用天数；
- 本季度已占用 = **本季度任务人日 + 本季度项目排期人日**；
- 剩余 = 可用 − 已占用，**可以为负数**；负数直接显示红色「超载」；
- 项目是 **全局维度**：总规划人日、工作项、里程碑可以跨季度；本季度只统计安排周落在 Q4 的工作项。

## 重点可点

| 操作 | 效果 |
| --- | --- |
| 顶部黑色刘海 / 点桌面空白 / `Esc` | 展开、收起面板 |
| 右上角 `◐` | 循环切换 Noir / Ops / Aurora / Ember 四套皮肤 |
| 本周安排 → 上一周 / 下一周 / 回到本周 | W42 显示 5.25 / 5 人日；W43 显示 4.25 / 3 人日，-1.25 超载 |
| 项目 → 等保 2.0 整改 | 进入工作规划；编辑全局总规划人日、工作项人日、安排周；跨季度工作项可排到 2027 |
| 工作项改「安排周」 | 自动同步到对应周的「项目自动排期」，计入已排人日 |
| 工作项右侧箭头 | 跳到对应本周安排，直接看自动排期；跨季度工作项可跳到 2027 第 1 周 |
| 侧边栏「其它」| 容量与复盘 / 临时笔记 / 收藏链接 |
| 筛选行 `+ 分类` / 设置 → 分类 | 新增自定义分类，立即出现在选择器 |
| 季度规划 → 容量与复盘 | 打开容量与复盘页 |
| 年度总览 | 四个季度的人日容量与完成度 |
| ⌘K | 全局跳转：页面、季度、项目、未完成事项 |
| ⌘J / 右上角 AI | AI 抽屉；生成提案后确认写入 |
| 右上角铃铛 | 顶部提醒弹窗：完成 / 稍后 / 打开 |

提醒弹窗会在打开页面约 5 秒后自动出现一次（演示用）。不想被它打断用 `?noreminder=1`。

```text

/?view=quarter&theme=ops&noreminder=1      # 季度规划 · Ops

```

## 项目规划模型

```text
Project（全局维度）
├─ plannedDays          全局总规划人日（可直接编辑）
├─ startDate / endDate  跨季度判断依据
├─ workItems[]          工作项
│   ├─ title
│   ├─ plannedDays      该工作项规划人日
│   ├─ weekKey          安排周 → 自动进入该周本周安排
│   └─ status           todo / done
└─ milestones[]        里程碑（全局项目进度 = 已完成里程碑 / 总里程碑）
```

本季度 vs 全局：

- 项目列表和项目详情标的都是 **全局规划**；
- 项目详情单独标 **本季度排期**（安排周落在当前季度的工作项人日）；
- 季度规划容量只扣 **本季度任务 + 本季度项目排期**，跨季度部分不占当季；
- 项目结束日期超过当前季度，标 **跨季度 / 有风险**；项目状态为 risk 也标 **有风险**。

## 数据口径

- 时间冻结在 **2026-10-17（周六）19:22**；
- 2026 Q4：62 个工作日 − 2 天年假 = **60 人日可用**；
- 本季度任务 48 人日 + Q4 项目排期 10.5 人日 = 已占用 58.5 人日，完成度 32%；
- 全局项目 5 个、总规划 50 人日，其中 3 个跨季度；
- 2026 全年：按日历引擎计算 **247 个工作日 / 245 人日可用**；
- 2026 官方日历：10/1–10/7 国庆假、10/10 调休上班、10/20–10/21 年假；
- 2027 年数据未发布，明确显示“按周末规则估算 + 待更新”。
