# Q-Panel · 可点击 UI 原型

Q-Panel 是给应用安全负责人自用的「季度作战工作台」：本季度任务 → 周计划 → 全局项目里程碑，容量、提醒和 AI 串成一条闭环。

**当前阶段：v0.3 可点击 UI 原型（假数据，未接 Electron / 真实存储 / 模型）。**

## 立即体验

开发服务器已启动：

## 主工作台只有三项

- **首页**：本季度容量与季度任务；
- **周计划**：周切换、7 天日期条、项目自动排期、本周必做；
- **项目**：全局项目 → 项目工作规划（全局总规划 / 工作项 / 本季排期 / 里程碑）。

统计、随笔记、链接收藏在 **顶栏「工具」菜单**。

## 人日口径（这一版重点）

- **1 人日 = 1 个正常工作日**；不再按小时折算；
- 支持 `0.25 / 0.5 / 0.75 / 1.25` 等半天粒度；
- 季度可用 = 工作日 − 请假/占用天数；
- 本季度已占用 = **本季度任务人日 + 本季度项目排期人日**；
- 剩余 = 可用 − 已占用，**可以为负数**；负数直接显示红色「超载」；
- 项目是 **全局维度**：总规划人日、工作项、里程碑可以跨季度；本季度只统计安排周落在 Q4 的工作项。

## 重点可点

| 操作 | 效果 |
| --- | --- |
| 顶部黑色刘海 / 点桌面空白 / `Esc` | 展开、收起面板 |
| 右上角 `◐` | 切换 Noir / Ops 两套皮肤 |
| 周计划 → 上一周 / 下一周 / 回到本周 | W42 显示 5.25 / 5 人日；W43 显示 4.25 / 3 人日，-1.25 超载 |
| 项目 → 等保 2.0 整改 | 进入工作规划；编辑全局总规划人日、工作项人日、安排周；跨季度工作项可排到 2027 |
| 工作项改「安排周」 | 自动同步到对应周的「项目自动排期」，计入已排人日 |
| 工作项右侧箭头 | 跳到对应周计划，直接看自动排期；跨季度工作项可跳到 2027 第 1 周 |
| 顶栏 `工具`（四宫格） | 统计与容量 / 随笔记 / 链接收藏 |
| 季度页 → 统计 | 打开统计与容量页 |
| 年度总览 | 四个季度的人日容量与完成度 |
| ⌘K | 全局跳转：页面、季度、项目、未完成事项 |
| ⌘J / 右上角 AI | AI 抽屉；生成提案后确认写入 |
| 右上角铃铛 | 顶部提醒弹窗：完成 / 稍后 / 打开 |

提醒弹窗会在打开页面约 5 秒后自动出现一次（演示用）。不想被它打断用 `?noreminder=1`。

## 直接链接

```text
/?view=quarter&theme=noir&noreminder=1     # 首页 · Noir
/?view=quarter&theme=ops&noreminder=1      # 首页 · Ops
/?view=week&theme=noir&noreminder=1        # 周计划
/?view=projects&theme=noir&noreminder=1    # 全局项目
/?view=stats&theme=noir&noreminder=1       # 统计（工具）
/?view=notes&theme=noir&noreminder=1       # 笔记（工具）
/?view=links&theme=noir&noreminder=1       # 链接（工具）
/?view=quarter&ai=1&noreminder=1           # AI 抽屉
/?view=quarter&settings=1&noreminder=1     # 设置
/?view=quarter&reminder=1                  # 提醒弹窗
/?collapsed=1&noreminder=1                 # 收起后的刘海态
```

## 项目规划模型

```text
Project（全局维度）
├─ plannedDays          全局总规划人日（可直接编辑）
├─ startDate / endDate  跨季度判断依据
├─ workItems[]          工作项
│   ├─ title
│   ├─ plannedDays      该工作项规划人日
│   ├─ weekKey          安排周 → 自动进入该周周计划
│   └─ status           todo / done
└─ milestones[]        里程碑（全局项目进度 = 已完成里程碑 / 总里程碑）
```

本季度 vs 全局：

- 项目列表和项目详情标的都是 **全局规划**；
- 项目详情单独标 **本季度排期**（安排周落在当前季度的工作项人日）；
- 首页容量只扣 **本季度任务 + 本季度项目排期**，跨季度部分不占当季；
- 项目结束日期超过当前季度，标 **跨季度 / 有风险**；项目状态为 risk 也标 **有风险**。
